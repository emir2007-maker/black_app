# Black App

## Project Description

Black App is a Laravel application developed as part of a university project. This repository contains the source code and files used to develop and demonstrate the application.

## Technologies Used

- PHP
- Laravel
- PostgreSQL
- HTML
- CSS
- JavaScript

## Requirements

- PHP
- Composer
- PostgreSQL
- Node.js and npm

## Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/emir2007-maker/black_app.git
   ```

2. Navigate to the project directory:

   ```bash
   cd black_app
   ```

3. Install the PHP dependencies:

   ```bash
   composer install
   ```

4. Create your environment configuration file:

   ```bash
   copy .env.example .env
   ```

5. Generate the application key:

   ```bash
   php artisan key:generate
   ```

6. Configure your database credentials in the `.env` file.

7. Run the database migrations:

   ```bash
   php artisan migrate
   ```

8. Start the development server:

   ```bash
   php artisan serve
   ```
